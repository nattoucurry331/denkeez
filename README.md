# Denkeez(デンキーズ)

> **電気工事の平面図エディタ** — 元請けから来る平面図 PDF 上に照明・スイッチ・コンセント・配線などを書き込み、拾い出し(数量集計)から見積連携までを支援する Windows デスクトップアプリ。

## このアプリは何か

北海道の建設会社・**有限会社 北嶺建設** の協力業者である電気工事職人からの「平面図に器具位置を書き込めるツールが欲しい」という相談を発端に、**事務所/自宅の Windows PC** で使える図面エディタとして開発しているアプリです。

汎用 CAD(JW_CAD / AutoCAD)が「機能が多すぎて使いづらい」「電気工事に特化していない」という現場の声に応える形で、**電気工事の拾い出しに必要な機能だけを揃えた、シンプルで分かりやすい UI** を目指しています。

ビルド・配布・運用は北嶺建設で行い、現役の電気工事職人さんからフィードバックをいただきながら継続改善しています。

## できること(β版時点)

| 機能 | 内容 |
|---|---|
| **PDF 取り込み** | 元請けからの平面図 PDF を読み込み、背景として表示 |
| **スケール校正** | 既知寸法の 2 点クリック → 実寸入力で図面の縮尺を取得 |
| **シンボル配置** | JIS C 0303 準拠の電気記号 20 種(照明 6 / スイッチ 5 / コンセント 4 / 弱電 3 / その他 2)を配置・移動・回転・複数選択 |
| **配線描画** | シンボル間を 4 種類の配線種別(天井ふところ実線 / 床下破線 / 壁内隠蔽点線 / 露出)で結ぶ。中継点経由可 |
| **レイヤー管理** | 標準 5 レイヤー(照明回路・コンセント回路・弱電・換気空調・寸法注記)+ 元図面レイヤー、ユーザー追加可。表示 ON/OFF・ロック・色設定・並び替え |
| **拾い出し集計** | シンボル種別ごとの数量・配線種別ごとの総長を右下パネルで自動表示 |
| **アンドゥ・リドゥ** | Ctrl+Z / Ctrl+Y、最大 50 ステップ |
| **ズーム・パン・ミニマップ** | マウスホイールでズーム、Space + ドラッグでパン、右下にミニマップ |
| **グリッド** | 910mm / 455mm / 100mm / 50mm 切替(和室基準対応) |
| **PDF 出力** | 用紙サイズ A4/A3/A2/A1 + 図面実寸選択、出力レイヤー選択、ベクター描画 |
| **CSV 出力** | 拾い出し結果を見積管理アプリ向けに UTF-8 BOM 付き CSV で出力 |
| **自動保存・復旧** | 未保存の状態でアプリ閉じる際に確認ダイアログ |

## まだできないこと(今後の対応予定)

- **シンボル種別のユーザー追加**(現状 20 種固定 / 要望次第で対応)
- **ケーブル種別のユーザー追加**(現状 6 種 / 「その他」+自由入力で凌ぐ)
- **タイトル枠 / 印刷プレビュー**(F-22)
- **見積管理アプリとの連携(直接 API)**(F-21、現状は CSV 経由)
- **iPad 対応**(F-24)
- **クラウド同期**(F-24)

詳細は [REQUIREMENTS.md](REQUIREMENTS.md) を参照。

## β版インストール手順

### 1. ダウンロード

[Releases ページ](https://github.com/nattoucurry331/denkeez/releases) から最新版 `Denkeez_x.x.x_x64-setup.exe` をダウンロードしてください。

### 2. インストール

ダウンロードした .exe をダブルクリック → インストール画面の指示に従う。

> ⚠️ **「WindowsによってPCが保護されました」と表示された場合**:
> β版はコード署名証明書を取得していないため警告が出ます。
> 「**詳細情報**」をクリック → 「**実行**」ボタンで進めてください。
> 北嶺建設が配布している正規ビルドであることを確認したい場合は、本リポジトリの最新コミット(`main` ブランチ)からビルドしたものか、Issue でご質問ください。

### 3. 初回起動

- スタートメニューに「Denkeez」が追加されます
- 起動時にメールアドレスの入力をお願いしています(任意ですが、不具合修正のお知らせや機能追加情報をお送りします。詳しくは下記「サポートについて」を参照)

### 動作環境

| 項目 | 必要要件 |
|---|---|
| OS | Windows 10 (x64) / Windows 11 |
| メモリ | 4 GB 以上 (8 GB 推奨) |
| ストレージ | 200 MB 以上の空き |
| 画面解像度 | 1280×800 以上 |
| WebView2 ランタイム | Windows 11 標準搭載、Windows 10 は最近の更新で大半搭載済み |

## 自動アップデート

β版は GitHub Releases から自動更新されます:

- アプリ起動時にバックグラウンドで最新版をチェック
- 新しいバージョンがあれば、メニューバー右端に「🔔 更新があります」と表示
- クリックすると更新内容と「今すぐ更新」「あとで」ボタンが出ます
- 更新中は数十秒〜1 分程度。終わると自動で再起動

> ネット接続がない環境(現場 PC など)では自動更新は走りません。
> 事務所に持ち帰ってネット接続するか、新しい .exe を手動でダウンロード・上書きインストールしてください。

## 開発者向け情報

開発・ビルド手順は [docs/dev-setup.md](docs/dev-setup.md) を参照(整備中)。

技術スタック:
- **フロントエンド**: TypeScript + React 18 + Vite 6 + Zustand 5(plain v5、immer 不採用)
- **描画**: Konva.js + react-konva
- **PDF 表示**: PDF.js
- **PDF 出力**: jsPDF(ベクター描画)
- **アプリ形態**: Tauri 2(Rust バックエンド + WebView2 フロント)
- **データ保存**: JSON(.dkz、Phase 3 で ZIP 化予定)

詳細な設計判断は [docs/architecture.md](docs/architecture.md) と [REQUIREMENTS.md](REQUIREMENTS.md) を参照。
