# Denkeez プライバシーポリシー

**最終更新日**: 2026 年 5 月 1 日
**バージョン**: 1.0
**事業者**: 有限会社 北嶺建設(以下「当社」)

本プライバシーポリシーは、当社が提供するソフトウェア「Denkeez(デンキーズ・仮称)」(以下「本ソフトウェア」)におけるユーザーの個人情報の取り扱いについて定めるものです。

---

## 1. 取得する個人情報

本ソフトウェアでは、以下の場合に限りユーザーの個人情報を取得することがあります。

| 取得タイミング | 取得項目 | 取得方法 |
|---|---|---|
| インストール後の任意登録 | メールアドレス、表示名(任意)、所属(任意) | アプリ内またはウェブフォーム |
| 不具合報告・お問い合わせ時 | メールアドレス、お問い合わせ内容 | GitHub Issue / メール |
| 自動更新チェック時 | IP アドレス(GitHub のサーバログ) | HTTPS 通信(技術的に発生する一般的なログ) |

**本ソフトウェアは、ユーザーが作成したプロジェクトファイル(.dkz)・図面 PDF・出力 CSV / PDF などの業務データを当社サーバーに送信することはありません。** すべてユーザー自身の PC 内で完結します。

---

## 2. 利用目的

取得した個人情報は、次の目的のために利用します。

1. **本ソフトウェアのサポート連絡**
   不具合報告への返信、操作方法に関するご質問への回答など。
2. **本ソフトウェアの重要なお知らせ**
   セキュリティ更新、互換性の重要な変更、サービス継続に関わる連絡など。
3. **本ソフトウェアの機能更新・改善のお知らせ**
   新バージョンの公開案内、機能追加・変更の告知、利用 Tips の配信など。
4. **当社が提供する関連サービス・他ソフトウェアのご案内**
   建設業 DX に関連する当社の他アプリケーション、ツール、コラム、セミナー等のご案内。
5. **ユーザーフィードバックの収集と分析**
   サービス改善のためのアンケート依頼、機能要望の集計など。

**4 の「他サービスの案内」は、当社が直接提供するものに限定** します。第三者の広告配信は行いません。

---

## 3. 第三者提供

当社は、ユーザー本人の同意なく、取得した個人情報を第三者に提供しません。
ただし、以下の場合は除きます。

- 法令に基づく場合(裁判所からの開示命令、警察からの照会等)
- 人の生命・身体・財産の保護のために必要があり、本人の同意を得ることが困難な場合

---

## 4. 配信の停止(オプトアウト)

利用目的 3・4・5 に基づくお知らせ配信は、いつでも停止いただけます。

- 配信メール末尾の「**配信停止**」リンクをクリック
- または、本ポリシー末尾の連絡先まで「配信停止希望」とご連絡

停止後も、利用目的 1(サポート連絡)・2(重要なお知らせ)に関する連絡は継続させていただく場合があります。

---

## 5. 開示・訂正・削除の請求

ご自身の個人情報について、開示・訂正・削除を請求できます。本ポリシー末尾の連絡先までご連絡ください。本人確認のうえ、合理的な期間内に対応いたします。

---

## 6. 安全管理措置

当社は、取得した個人情報を漏洩・滅失・毀損から保護するため、以下の措置を講じます。

- メールアドレスのリストは、配信プラットフォーム(Mailchimp / Substack 等の大手サービス)上で管理し、当社代表のみがアクセス権を持ちます
- 業務データ(プロジェクトファイル等)は当社サーバに送信されないため、漏洩リスクは構造的にゼロです
- GitHub 上のソースコードリポジトリには、いかなる個人情報も保存しません

---

## 7. クッキー・トラッキング

本ソフトウェアはデスクトップアプリケーションであり、Web トラッキング Cookie は使用していません。
ローカルストレージ(`localStorage`)を UI 設定の保存(レイヤーパネル展開状態等)に利用しますが、個人を識別するデータは保存しません。

---

## 8. 自動更新通信について

本ソフトウェアは、起動時に GitHub Releases の最新バージョン情報(`latest.json`)を取得します。この通信は HTTPS で行われ、GitHub のサーバ側に通常のアクセスログ(IP アドレス、UserAgent 等)が記録される可能性があります。これは GitHub のプライバシーポリシーが適用されます。

GitHub プライバシー声明: https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement

---

## 9. お子様の情報

本ソフトウェアは業務(電気工事・建設業)向けであり、未成年からの個人情報取得は想定していません。

---

法令の改正、利用目的の追加・変更などに応じて、本ポリシーを改訂することがあります。重要な変更がある場合は、登録されたメールアドレスにご連絡するとともに、本ドキュメントの「最終更新日」を更新します。
