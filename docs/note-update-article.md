# 【アップデートのお知らせ】図面エディタ「Denkeez(デンキーズ)」がこの数週間で大きく進化しました

電気工事の平面図づくりを楽にするデスクトップアプリ **Denkeez(デンキーズ・仮称)** を開発している北嶺建設です。

このところ集中して改良を重ね、現場で「あると助かる」機能がぐっと増えました。今回はその内容をまとめてご紹介します。

> Denkeez は、元請けさんからもらう平面図(PDF)の上に、照明・スイッチ・コンセントなどの記号を置いて、**拾い出し(数量集計)から見積までをスムーズにする**ことを目指したアプリです。Windows で動き、**無料**でお使いいただけます(現在ベータ版)。

## 🆕 今回の主なアップデート

### ① 図面に文字を自由に書き込めるようになりました

図面の好きな位置をクリックして、**注記(メモ)** を入力できます。

- ダブルクリックで後から編集、ドラッグで移動、文字の大きさ・色も変更可能
- 書いた文字は **PDF 出力にもそのまま出ます**(日本語もOK)

「ここは要確認」「分電盤」など、現場の申し送りを図面に直接残せます。

### ② 寸法を「その場で測る」「図面に残す」

- **寸法を測る**:2点をクリックするだけで実寸を表示(縮尺を合わせておけば「3,640mm / 3.64m」のように)
- **寸法線を引く**:測った寸法を図面に線として残し、**PDF にも出力**
- きれいに引けるよう、**グリッド(910/455mm など)への吸着**と**直角ガイド**にも対応

拾い出しだけでなく、納品図に寸法を入れて渡せるようになりました。

### ③ メーカー商品(品番)を図面に貼れる

ダウンライトなどを、メーカーの実際の商品として扱えます。

- 品番から**公式ページをワンクリックで開いて**画像を入手 → 取り込み
- 図面上の**表示サイズを指定**、**白い背景を透明に**、**余白のトリミング**まで対応
- 拾い出しは**品番ごとに集計**されます

### ④ 拾い出しから見積へ(連携)

配置した記号・配線を **CSV / JSON で出力**できます。

- 種別・規格・数量・回路番号・縮尺をまとめて書き出し
- 見積管理ソフトへの取り込みを想定した形式です(配線はケーブル種別ごとに m で計上)

### ⑤ 表題欄(タイトル枠)+ 印刷プレビュー

- 図面の隅に **工事名・図面名・縮尺・日付・作成者・会社名**の表題欄を付けられます(縮尺は自動入力)
- **PDF 出力前にプレビュー**で仕上がりを確認 → 向き・用紙サイズ違いの印刷事故を防げます

### ⑥ マウスだけで、もっと操作しやすく

- **「↶ 元に戻す / ↷ やり直す / 🗑 削除」ボタン**を追加(キーボードが苦手でも安心)
- **PDF の中の文字を自動で読み取り**、専用レイヤーに保存 → 必要な文字だけ**1つずつ選んで**注記化、または**全件まとめて**取り込み

### ⑦ 起動するだけで最新版に

アプリを開くと**自動で最新版に更新**されます。今回ご紹介した機能も、すでにお使いの方には自動で届きます。
